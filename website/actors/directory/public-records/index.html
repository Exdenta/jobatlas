Public APIs and documentation

Public records

Find public public records APIs, understand their outputs, and follow their Store listings and documentation before choosing a tool.

Each listing links to its own current input and pricing. Optional modes and output formats differ between products.

NHS UK Providers Scraper — GP, Pharmacy, Dentist, Care Home

Search the NHS ODS provider directory by name, postcode or provider type. Returns ODS codes, addresses and published phone numbers.

Open on Apify (nomad-agent) · Public documentation

PTAB Trials Scraper — USPTO IPR/PGR Tracker + Webhook Alerts

Retrieve USPTO PTAB proceedings, parties, status, dates and institution or final-written decisions. Supports webhook snapshots. Live mode requires a USPTO Open Data Portal API key; the default preview returns labelled samples.

Open on Apify (nomad-agent) · Public documentation

SPAC Redemptions Scraper — SEC EDGAR Lifecycle Tracker

Retrieve SEC EDGAR SPAC filings, merger communications, meeting dates and reported redemption figures. Missing financial values remain unavailable.

Open on Apify (nomad-agent) · Public documentation

UK Case Law Scraper — BAILII Alternative, Judgments API

Search The National Archives Find Case Law judgments by court, party, judge, date and citation. Returns links with optional judgment text and legislation references.

Open on Apify (nomad-agent) · Public documentation
